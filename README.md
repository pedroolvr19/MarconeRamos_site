# Marcone Ramos — Nutrição para a vida real

Site institucional responsivo, em HTML, CSS e JavaScript, sem dependências de compilação.

## Prévia local

Execute `node site/serve.cjs` e acesse http://127.0.0.1:4173.

Os arquivos prontos para hospedagem estão em `site/dist/`.

## Publicação

Hospedado na Vercel a partir deste repositório: diretório raiz `site/dist`, sem comando de build. Cada `git push` na branch `main` atualiza o site.
